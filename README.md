## 📋 İçerik

Kişisel portfolyo ve CV web sitesi. Projelerimi, iş deneyimlerimi ve teknik yeteneklerimi bir arada sunar.

- **Hero** — Kısa tanıtım ve sosyal linkler
- **Hakkımda** — Eğitim ve genel bilgiler + CV indirme
- **Yetenekler** — Teknoloji stack'i ve sertifikalar
- **Deneyim** — Staj geçmişi (METUnic, Yenimahalle Belediyesi, SVD Sistem)
- **Projeler** — Akıllı Sera Sistemi, SmartStock, NEXORA E-Ticaret
- **İletişim** — E-posta, LinkedIn, GitHub

## 🚀 Yerel Geliştirme

```bash
# Bağımlılıkları yükle
npm install

# Geliştirme sunucusunu başlat
npm run dev

# Üretim derlemesi
npm run build

# GitHub Pages'a deploy et
npm run deploy
```
